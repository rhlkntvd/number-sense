# Number Sense

A configurable mental arithmetic drill built with TypeScript

## Features

- Addition, subtraction, multiplication, and division
- Configurable operand ranges, including negative numbers
- Count mode with a fixed number of problems
- Duration mode with a countdown timer
- Automatic advancement after a correct answer

## Stack

- TypeScript
- HTML / CSS
- Vite
- Vitest

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Testing

```bash
npm run test:run
```
